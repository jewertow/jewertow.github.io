  • Secretless control plane Draft

    istiod currently reads every Secret in the cluster to serve gateway certificates over SDS. This proposal adds an opt-in mode where the gateway resolves its own credentials, so the Secret read is authorized by Kubernetes RBAC instead of in istiod's process.
