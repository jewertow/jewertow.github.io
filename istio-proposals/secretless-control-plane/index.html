Secretless control plane

Today istiod is a credential broker: it holds get/watch/list secrets cluster-wide, reads gateway certificates from a cluster-wide informer, and decides in its own process whether the proxy may have them. This proposal adds an opt-in mode — pilot.secretless.enabled=true — in which istio-agent resolves kubernetes:// credentials from its own namespace with the pod's projected token, so the Kubernetes API server's RBAC evaluation becomes the thing that enforces the decision.
